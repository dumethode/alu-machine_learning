# Advanced Linear Algebra

This project covers determinants, minors, cofactors, adjugates,
inverses, eigenvalues and the definiteness of a matrix.

## Requirements

- Ubuntu 16.04 LTS, python3 (version 3.5)
- numpy (version 1.15)
- pycodestyle (version 2.5)
- All files are executable and end with a new line
- All files start with `#!/usr/bin/env python3`

## Files

0-determinant.py, 1-minor.py, 2-cofactor.py, 3-adjugate.py,
4-inverse.py, 5-definiteness.py
